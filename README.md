# hello-world-python
Hello World in Python

A minimal Flask app that serves "Hello, World!" in the browser.

Requires Python 3.13+.

## Run

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python src/app.py
```

Then open http://127.0.0.1:5000 in your browser.
